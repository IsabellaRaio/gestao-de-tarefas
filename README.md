# TechFlow Solutions - Sistema de Gerenciamento de Tarefas

Este projeto consiste no desenvolvimento de um sistema básico de gerenciamento de tarefas (CRUD) voltado para uma startup de logística. O objetivo é permitir o acompanhamento do fluxo de trabalho em tempo real, a priorização de tarefas críticas e o monitoramento do desempenho da equipe por meio de práticas modernas de Engenharia de Software e metodologias ágeis[cite: 1].

---

## Escopo Inicial do Projeto

O sistema será uma API robusta e simplificada construída em Python (FastAPI), que permitirá[cite: 1]:
* **Criar tarefas** com título, descrição e status de progresso[cite: 1].
* **Visualizar tarefas** pendentes e concluídas.
* **Atualizar o status** ou detalhes de tarefas existentes[cite: 1].
* **Deletar tarefas** que não são mais necessárias[cite: 1].

---

## Metodologia Ágil

Para a gestão e acompanhamento do ciclo de vida de desenvolvimento, adotei o framework **Kanban**[cite: 1]. 
O progresso das tarefas está mapeado no quadro interativo do **GitHub Projects** utilizando as seguintes colunas[cite: 1]:
1. **To Do (A Fazer):** Tarefas aguardando início[cite: 1].
2. **In Progress (Em Progresso):** Tarefas sendo desenvolvidas no momento[cite: 1].
3. **Done (Concluído):** Tarefas que passaram por testes e foram finalizadas[cite: 1].

---

## Tecnologias Utilizadas

* **Linguagem Principal:** Python 3.10+[cite: 1]
* **Framework Web:** FastAPI (construção das rotas do CRUD)[cite: 1]
* **Testes Automatizados:** Pytest (garantia da qualidade de software)[cite: 1]
* **Integração Contínua (CI):** GitHub Actions (automação de testes em cada push)[cite: 1]
